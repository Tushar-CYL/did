PART 3 — WHAT TO SCRAPE (DETAILS OF EACH FIELD)
----------------------------------------------------------------

RULE:
- HIRING data   = INDIA ONLY, open roles, posted in the last month.
- ALL OTHER data = GLOBAL, last month.
- Nothing is faked. If a site has no scrapable hiring, hiring is left blank;
  its global signals still show.

A) INDIA HIRING — one row per open role (India only):
   - Company
   - Role / job title
   - Location (city) + country
   - Department / business domain (Finance, Supply Chain, Clinical/R&D,
     Risk & Compliance, Manufacturing, Commercial & Marketing, HR & People,
     Technology / IT)
   - Skills / technologies detected (SAP, Azure, AWS, Power BI, Python,
     GenAI, etc.)
   - Seniority level (Executive / Manager-Lead / Senior / Mid / Junior)
   - Experience (years) where stated
   - Employment type (Permanent / Full-time vs Contract / Temporary / Intern)
   - Posted date + aging (days open)
   - Critical-role flag (hard-to-fill / high-priority)
   - Job ID + source URL (link back to the live posting)
   - Hiring manager (ONLY if named in the posting; never guessed)

B) MARKET INTELLIGENCE — GLOBAL, last month, 5 fields per company:
   (sources: news + official company newsrooms / investor relations +
    SEC / RNS filings)
   1. Hiring            — workforce / recruitment / headcount news
   2. Vision & strategy — leadership, reorganisation, strategic direction
   3. Partnerships      — alliances, technology / cloud / AI vendor deals
   4. Financial         — results, earnings, revenue, funding, acquisitions
   5. Expansion         — new facilities, investments, India / GCC capability

C) STRATEGIC SIGNALS (derived, per company):
   - Partnership signals
   - Vision / strategy shifts
   - Tool-gravitation (which vendors/tech they lean on -> the EY angle)
   - Short LLM takeaways / "so what for EY"

D) NEWS RANKING (INTERNAL ONLY):
   - News items are RANKED by correlation / relevance to the company.
   - This ranking is used internally to order/pick items.
   - DO NOT show the rank/score in the UI.

E) NOT ALLOWED:
   - Do NOT scrape LinkedIn (no LinkedIn PII).


----------------------------------------------------------------
PART 4 — WHAT THE MANAGER NEEDS (DELIVERABLES / EXPECTATIONS)
----------------------------------------------------------------
1. Per-company India account intelligence across all ~50 target accounts,
   combining India hiring + global market insights.

2. TWO deliverables, regenerated together:
   a) DASHBOARD — a static web dashboard (open in a browser, no login).
   b) BI EXCEL  — a Power BI-ready Excel workbook.

3. ONE command runs the whole pipeline:
   scrape -> process -> rank -> build Excel -> update the UI.

4. Get data for ALL 50 companies by any available means.
   Blank is acceptable ONLY when a site is genuinely unscrapable.
   Never fake data.

5. FRESH every run — each run re-scrapes / recomputes; do not keep showing
   old data. The dashboard AND Excel must reflect the latest run.

6. Insights must be clean, clear and understandable for EVERY client:
   - No duplication (same event repeated across fields/cards).
   - Proper, straight, readable sentences.

7. UI is fixed — only ADD values into the existing UI; do not change the
   UI layout/design.

8. Hiring = India only; everything else = global, last month (the core rule).
