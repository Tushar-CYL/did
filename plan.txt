ACCOUNTSIGNAL — EY INDIA ACCOUNT INTELLIGENCE ENGINE
Implementation Plan + Build Status
================================================================

GOAL
One Python command: scrape -> store JSON -> enrich/rank with EY's LLM ->
build a Power BI-ready Excel -> populate a professional web dashboard.
Fresh every run. No faked data. No LinkedIn.
HIRING = India only, last month.  ALL OTHER DATA = global, last month.
PRIORITY: news / market-intelligence insights matter MORE than hiring.

KEY DECISIONS
- Build & test on personal laptop (D:\tushar\scrape); then copy the whole
  folder to the office laptop and confirm it runs there. => portable, pure
  Python, pip-installable, no admin.
- LLM = EY internal EYQ endpoint (OpenAI-compatible), model gpt-5.2.
  Credentials in .env (never committed).
- Scraping = FREE & robust: public ATS JSON APIs first; Playwright only as a
  later fallback. News = Google News RSS (free) + newsroom + SEC EDGAR.

----------------------------------------------------------------
ARCHITECTURE  (src/accountsignal/)
----------------------------------------------------------------
  config.py            paths + .env + companies.yaml loader
  http.py              shared session: UA, retries, per-host rate limit
  store/schema.py      dataclasses (Role, NewsItem, MarketIntel, CompanyRecord)
  store/io.py          atomic JSON read/write (fresh each run)
  scrape/hiring/
     detect.py         ATS fingerprinting (Workday/Eightfold/Phenom/SF/...)
     base.py           India filter + date parsing + seniority heuristics
     workday.py        Workday CXS JSON API adapter  [WORKING]
     dispatch.py       route careers URL -> adapter
  scrape/news/
     google_news_rss.py  free RSS per company per category, last-month
     collect.py          dedupe + best-category assignment + caps
  enrich/              [PHASE 2] eyq_client, classify_hiring, market_intel,
                       signals, rank (internal, hidden in UI)
  output/              [PHASE 3] excel.py (Power BI), dashboard.py
  run.py               ONE-command orchestrator

DATA MODEL  (data/normalized/companies.json = single source of truth)
  per company: hiring_india[], market_intel{hiring,vision,partnerships,
  financial,expansion}, signals{}, scrape_errors[] (transparency).
  Internal news _score is stripped from the dashboard payload.
